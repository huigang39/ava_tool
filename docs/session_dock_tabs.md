# 会话中的 dock 页面

保存 `.ava` 会话（Ctrl+S）时，会记录每个 dock 分组当前选中的标签页，以及最后聚焦的 dock 窗口。启动时先在最近会话窗口中选择 `.ava` 文件，选中后加载该会话并恢复这些页面；程序不会自动载入上一次使用的会话。

切换到希望下次打开的页面后，保存一次会话即可。只有切换标签页不会自动修改或保存会话。

旧版 `.ava` 文件仍可读取，并尝试根据已有布局中的选中标签恢复页面。已关闭或不存在的页面会被忽略；恢复完成后可以正常切换标签页。

回归测试：

```powershell
python tests/run_sim_sampler_test.py --dock-session
```

测试覆盖实际 `.ava` 保存、重新启动、运行中加载、多个 dock 分组、焦点恢复、旧格式以及缺失页面。

点击 Dock 页签或工具窗口的 X 会弹出关闭确认。选择“取消”或按 Esc 保留页面及原有页签位置；选择“关闭”后移除对应页面。未选中的页签也使用同样流程。
