# UI 设计约定

桌面界面固定采用 macOS 控件与 island 工作区，设置只提供明暗模式和配色。`platform_style.hpp` 负责控件尺寸和完整 ImGui 色板，`ui_theme.hpp` 负责动作及状态含义，`ui_icons.hpp` 提供统一的矢量图标。系统继续负责窗口装饰和文件对话框。

## 色板

| Token / 用途 | 规则 |
| --- | --- |
| `WindowBg` / 主工作区 | 深色使用低亮度中性色；浅色使用接近白色的中性色 |
| `PopupBg`, `MenuBarBg`, `TableHeaderBg` | 同一层级的面板表面；保持文字对比度 |
| `FrameBg`, `Button`, `TabSelected` | 控件表面；Hover/Active 只改变少量明度 |
| `Text`, `TextDisabled` | 由明暗模式选择，不在业务面板中硬编码白色或黑色 |
| `CheckMark`, `SliderGrab`, `NavCursor` | 平台强调色，分别用于选中态、滑块和键盘焦点 |
| `Border`, `Separator`, 表格线 | 低对比度中性边界，不重复叠加粗边框 |

应用通过 `island_style.hpp` 的 `ApplyAppStyle` 统一生成 macOS 尺寸与圆角，配色提供海蓝、石墨、鸢紫、薄荷、玫瑰、琥珀。`platform_style.txt` 的旧平台选择不再应用，配色单独保存在 `color_scheme.txt`。所有配色支持浅色和深色，重建未缩放样式后再应用 DPI。原有平台色板函数仅作为底层兼容接口。

工作区保留原 DockSpace ID，增加画布留白、分隔间距和圆角卡片，旧布局仍可载入。Island 间隔与画布同色，中央显示类似 VS Code 的三个小圆点：左右面板间竖排，上下面板间横排，悬停和拖动时使用强调色，不绘制整条分隔杆。点阵随 DPI 缩放，仍使用原有间隔拖动调整大小；锁定大小的分隔不显示拖动提示。主工作区和浮动 Dock 组采用相同规则。控件间距保持紧凑，监视器选项里的滑块和下拉框填满可用宽度。明暗模式和六种配色统一放在“设置 → 外观”。

圆角使用 `design_tokens.hpp`：按钮、输入框和页签为 6 个逻辑像素，窗口为 12，浮层为 10；嵌套圆角按外圆角减内缩量计算，随 DPI 缩放。单位换算弹窗和右下角通知显式沿用浮层圆角，避免多窗口渲染的窗口边界规则把它们变成直角。

强调色基值如下（浮点色值四舍五入为 sRGB HEX）：

| 平台 | 浅色强调色 | 深色强调色 |
| --- | --- | --- |
| Windows | `#0067C1` | `#61CCFA` |
| macOS | `#0066CC` | `#459CFF` |
| GNOME | `#1C70D7` | `#61A6FA` |
| KDE | `#006FAC` | `#3DADE8` |

Windows 的基础表面为浅色 `#F3F3F3` / 深色 `#202020`，弹出层为 `#F9F9F9` / `#2B2B2B`，正文为 `#1A1F26` / `#F0F0F2`。成功、警示、危险使用 `#3DA86B`、`#C48A29`、`#C24542` 作为混色基值，再与当前控件表面混合；这些基值不直接作为整排按钮背景。前景和交互状态由主题函数计算并验证对比度。

普通动作使用 `Neutral`；唯一的主要动作使用 `Primary`。连接/开始为 `Success`，暂停/重置为 `Warning`，删除/断开为 `Danger`，忙碌状态为 `Muted`。主要动作可以填充强调色，其余语义按钮使用淡色表面和有对比度的文字。不要给一整排普通工具按钮分别填充高饱和度颜色。

状态文字使用 `ui::TextColored(color, format, ...)`。它保留原始透明度，并根据主题调整前景明度。用户选择的曲线颜色保留在曲线和色块中；需要作为文字显示时使用 `ui::ReadableTextColor(color, background)`，避免浅色曲线标签在浅色面板中消失。明确使用自定义背景的绘图区域应传入实际背景颜色。

## 图标

共享图标使用 24 单位坐标网格、统一线宽和轮廓风格，通过 ImDrawList 绘制并随字体/DPI 缩放。包含 Home、Open、Save、Search、Add、Device、Motor、Connect、Disconnect、Variables、Chart、Grid、Focus、More、Settings、Play、Pause、Delete、Back、Library、Properties、Success、Warning、Error、Info、Close。Motor 使用带散热筋、接线盒和输出轴的电机轮廓；SDK 控制台使用 Library，避免用芯片图标代替所有设备功能。通知的状态和关闭图标也使用这套矢量路径，不依赖 Font Awesome 私用区字符，避免显示为缺字问号。

```cpp
#include "gui/ui_icons.hpp"

if (ui::IconButton("连接###connect", ui::Icon::Connect, ui::BtnStyle::Success)) {
    // 执行连接
}
```

`IconButton` 保留原生 ImGui Button 的 ID、键盘焦点、导航和禁用行为。按钮宽度同时计算图标和文字，文本仍承担动作说明；受约束的宽度会裁剪并提供完整文字提示。`###id` 保持稳定 ID，`##id` 隐藏内部标识。装饰性图标使用 `ui::DrawIcon(drawList, icon, topLeft, size, color)`。

## 明暗模式

`appearance::ResolveDark` 支持系统、按时间、固定浅色、固定深色。默认白天区间为 07:00（含）到 19:00（不含），允许跨午夜；无效或相同时间边界回退至系统模式。平台偏好查询在后台运行，不阻塞绘制线程。Windows 读取应用主题偏好，macOS 查询系统外观偏好，Linux 优先匹配 KDE 或 GNOME 的明暗设置；读取失败保留调用方当前模式。

`python tests/run_platform_style_test.py` 验证明暗色板、语义按钮三种交互状态的文字对比度、时间边界、图标按钮 ID/禁用/尺寸、文字样式恢复、字体回退、DPI 反复切换和 Ctrl/Command。测试不能替代 macOS/Linux 实机外观检查。

## 点击打开与局部预览

辅助设置统一点击打开，点击弹窗外部、再次点击入口或 Esc 关闭，不再显示“收起”按钮；经过入口不会自动弹窗。点击弹窗内部或其子菜单不会关闭，外部点击保留输入框的编辑提交。窗口仍支持拖动和原生边缘调整大小，输入与子菜单优先处理 Esc。J-Link、画面工具、SDK 日志、参数目标与预设、符号浏览器、功能安全配置、记录器选项和“更多”均遵循这套规则。

只有变量记录器的统计和聚焦保留悬停预览。统计面板离开后自动收回，点击统计则显示固定侧栏；预览不改变绘图区。变量管理器的聚焦改为点击进入。

曲线示波器的名称、聚焦/还原、更多与统计入口贴在图框右上缘，不另占标题行。名称保留拖动排序和双击重命名；窄窗口优先保留操作入口，完整名称与重命名仍可从“更多”访问。浮层先处理点击再绘制到图形上方，避免按钮触发曲线平移、缩放或测量。表格和隐藏的示波器仍保留紧凑工具栏。

## 变量单位换算

单位换算在变量管理器或变量记录器表格的变量右键菜单中设置。未配置换算时，悬停变量值、曲线或图例都不会打开任何换算弹窗。选择物理量、原始单位和目标单位并应用后，变量身份相同的现有曲线通道立即继承设置；之后拖入变量记录器时也沿用该设置。各变量、深层成员与曲线通道独立保存配置，并随会话恢复；变量列表文件也保留变量配置。

| 物理量 | 支持单位 |
| --- | --- |
| 角位置 | rad、deg、rev、count |
| 转速 | rad/s、deg/s、rpm、rev/s、count/s |
| 直线位置 | mm、cm、m、um、in |
| 直线速度 | mm/s、cm/s、m/s、mm/min、m/min |

原始单位必须由用户确认，不按变量名称猜测。count/count/s 需要大于零的“每圈编码器计数”，应填写倍频后的有效计数；不自动推断减速比或丝杠导程，不跨角度/直线物理量换算。

换算只作用于变量记录器的游标读数。时域游标在原始值后同时显示目标单位，不包含绘图增益/偏置；图例悬停不显示换算弹窗。表格原文、曲线坐标、采集缓存、CSV 和设备写入保持原样。换算数值使用 double，不能替代原始整数的精确表示；FFT、枚举和布尔字段不提供物理单位换算。


## 状态、快捷键与会话

底栏显示实时 FPS 与所有监视器的快照数据点数，点数以 K/M/G 等十进制单位缩写，悬停显示完整数值；正常显示时不常驻“画面实时更新”，只有冻结时显示“画面已冻结”。J-Link 未连接时隐藏底栏的连接与采集状态。监视器工具栏显示按通道实际收到的数据统计的采样率，通道速率不同时显示范围；没有新采样时归零，目标频率单独标注。J-Link 页面显示实际收到的 HSS 流和成功 POLL 读取的字节速率。冻结画面不停止采集。

波形跟随最新有效采样点，无数据或采样停止时不随系统时间空跑。SDK LOCAL 变量只在成功读取新数据时推送带时间戳的采样；失败读取、写入确认和重复帧不产生新点，断连和重新加载会话均不会反复绘制缓存值。手动 LOCAL 变量继续按监视器设定频率采样。

空格冻结／恢复画面，Ctrl/Cmd+Shift+Delete 立即清空所有监视器的已采集数据。正在输入、操作控件或打开弹出菜单时，全局快捷键不抢占输入；长按不会重复触发。

变量管理器移除了函数浏览器区域。变量管理器和监视器的每个顶层结构体各是一张圆角卡片，范围随展开成员变化，卡片之间留窄间距；共用圆角表头和列宽。结构体的标题、普通成员和折叠的子结构体使用连续的同色色块，块内不画横向分隔线、不交替明暗。展开子结构体后，其标题和成员切换为下一层颜色的圆角卡片；所有层级名称使用同一个左对齐位置，不再逐层缩进；收起时融回父级色块。同层卡片保持同色，进入分组单独查看时也保持一致。背景绘制在原生表格的背景通道中，保留冻结表头、横向滚动、悬浮预览、编辑和拖拽；左键单击不会选中或高亮变量行。SDK 调用和既有变量绑定保留。

悬浮预览固定后可从标题栏的横向、纵向拖动柄分别调整宽度和高度，不会同比缩放字体或控件内容；标题栏继续用于拖动窗口位置。

结构体树表使用 `table_hierarchy.hpp` 的 `HierarchyTable` 和 `HierarchyCard`，圆角属于每个结构体，不在整个表格的空白区域再套卡片。其他平面数据表使用 `table_island.hpp` 的 `TableIsland`：表头与内容构成一张圆角卡片，采用独立表面、轻量表头和细轮廓。符号浏览、参数与结构体编辑、监视器统计、SDK 字段与调用参数表采用该容器；用于排列图形的布局表保持原样。两种容器均保留原生表格 ID 与设置，深浅色、配色和 DPI 缩放沿用全局主题。

变量表、观测器和曲线图例的右键菜单提供“复制”，输出可直接粘贴的三列文本：完整变量名、当前格式下的值、地址（仅在可用时填写）。结构体、数组递归包含其成员，包含未展开的成员；未采样的 J-Link 成员通过后台读取补齐，不阻塞绘制，读取失败或超时保留明确状态。变量表复制最多 100000 行，达到上限时附上截断说明。

“整数显示进制”改为“数值显示格式”，提供十进制、十六进制、八进制和二进制；不提供“跟随管理器”。各变量和结构体/数组子成员可独立设置，随会话和 `.var` 文件保存。变量表中，子成员显式设置在父级变更后仍保留；观测器的分组菜单可批量设置组内通道。浮点数的非十进制显示使用原始 IEEE 754 位模式，保留负零、NaN 载荷和完整位宽。观测器的最新原始字节与显示快照一同冻结，不从绘图用的近似值推测 f64 位模式；原始位不可用时明确显示。切换格式不改变采样、换算或写入；位模式下双击可打开十进制值编辑。

功能安全页的文件操作和筛选按钮使用 `FlowToolbar`，先横向排列，宽度不足时换行；说明与配置文件同排，对象状态汇总为一行。搜索框在宽窗口并排、窄窗口换行。SDK 配置入口置于语言标签栏右侧，调用日志置于数据分组标签栏右侧，不再各占一行；仍保留配置的展开状态及日志的悬停/固定行为。输入框使用独立底色和细边框，提升次要文字及禁用控件的可读性，选中标签增加强调线。六种配色的深浅模式均校验正文、数值和搜索提示的文字对比度。

参数配置页的打开状态、路径、预设目录、组件标签页及编辑草稿保存进 `.ava`，包括尚未完成的输入。Flash 等工具页的显示状态随会话恢复。工具设置、页面可见性和 Dock 布局参与未保存检测，成功保存和加载后建立新的基线。

## 服务器和存储

设置 → 服务器包含文件共享、网页部署、远程服务器三个标签。设置面板使用固定宽高，切换分页、部署状态或远程服务器内容时尺寸保持稳定，超出内容在面板内部滚动。网页部署选择含 `index.html` 的构建输出目录，默认端口 8091；文件共享继续使用 8090。网页服务支持 HTML/CSS/JavaScript、图片、字体、WASM 等静态资源，并可开启单页应用的页面路由回退。页面以局域网 IP 提供浏览器地址；服务器需要保持运行，系统防火墙需允许对应专用网络访问。后台服务端程序（如 Node/Python）不由静态网页服务执行。

设置 → 存储与清理分别显示日志和缓存的占用、文件数，可刷新统计或分别清理。统计与清理在后台执行；只处理应用的日志、采样缓存和远程下载目录，不递归删除用户选定的父目录，不跟随链接或目录联接。正在写入的日志与被占用的缓存保留，清理后显示释放空间并重新统计。

固定选项的单选控件统一使用 `choice_control.hpp` 的横向分段按钮，包括读写、数值格式、视图、采样模式、外观、语言与单位。选中项有清晰底色和轮廓，保留键盘操作与禁用状态；窄窗口或表格单元格按可用宽度换行。读写选项再次点击仍会应用到当前变量或建立成员覆盖。参数配置的预设入口与保存、另存为、恢复默认、写入、读取共用一行流式工具栏。

符号文件入口位于变量工具栏，将文件加载和符号浏览合并为一个按钮；悬停预览、点击固定，固定后入口高亮，固定状态随会话保存。固定后的悬浮窗可拖动标题移动，并可拖拽任意边框调整宽高。浏览器使用独立的可调尺寸滚动区和冻结表头，底部最后一行可以完整滚动显示。双击符号树或搜索结果中的变量会将其加入变量管理器；名称、地址和类型完全相同的变量不会重复加入变量管理器或当前变量记录器。符号数据重新加载时以版本号使搜索缓存失效，不需要清空搜索文字；搜索支持名称和地址，不再静默截断至 500 项，筛选后的数据重新应用排序。

示波器显示方式使用“波形 / 表格”。表格中可写枚举值使用单行下拉框，按当前数值格式标注实际枚举值；长选项列表在弹窗内滚动，未采样或未知值在预览中显示。展开下拉框不写入设备，选择选项才写入；只读行保持文本。

采样频率在监视器工具栏最右侧只显示一位小数的 Hz（如 `1250.3 Hz`）；多通道显示最快通道，悬停查看通道数量和频率范围。

错误信息使用 `ui::ErrorTextColor` / `ErrorText` / `ErrorTextWrapped` 的统一红色，并按深浅主题保证文字对比度；参数、设备、SDK 日志、服务器、下载和表格 `ERR` 均适用。通知沿用正文字号、浮层圆角和中性细边框，状态通过图标和有对比度的文字表达，不加侧边色条；错误通知的标题和正文均为红色。保存成功复用通知卡片；长内容自动换行，受视口高度约束时可滚动，保留关闭与操作按钮。

变量表的“进入”统一为“聚焦”。记录器分组和示波器支持悬停 300 ms 临时预览，移开或 Esc 恢复原聚焦和滚动位置，点击固定当前聚焦。原按钮区域只跟踪鼠标意图，不重复提交或绘制按钮；提交预览时消耗该次点击，防止落到新视图的数据编辑器上。预览不修改会话、采样或数据。波形按钮顺序为“统计、聚焦、更多”，“更多”点击打开。

变量管理器的刷新间隔滑块固定在工具栏右上角，显示毫秒，可 Ctrl+点击输入；列表操作、符号来源、工具和视图动作分组。参数页将目标选择、预设、文件保存/恢复及设备读写放在同一条可换行工具栏。目标通过悬浮面板搜索当前变量管理器的监视变量和已加载符号，选择即应用。功能安全的 JSON 加载与重载放在独立工具栏的配置浮窗，与“系统变量／单值解析”模式标签分开。标量绑定从变量管理器选择。

变量及成员数值变化时出现短暂的脉冲高亮，持续变化保持闪烁，稳定后渐隐；初次显示和读取错误不触发数值高亮。成功通知的标题、正文，以及参数保存、恢复、读取和写入成功提示使用绿色。

局域网网页监听所有 IPv4 网卡。跨子网或 VLAN 的客户端还需要网络路由及 ACL 放通对应 TCP 端口；网页启动成功和本机返回 HTTP 200 并不能证明另一子网已获准访问。

面板名称统一为“变量记录器”“动态库调用器”和“J-Flash”；自定义标题保留，旧的默认标题和 J-Flash 停靠信息兼容迁移。变量管理器使用较短的常驻搜索输入框，可检索折叠成员、数组下标、成员别名和地址；结果在变量表上方内联展开，点击后展开祖先并滚动定位。变量记录器以及设备、功能安全、参数与 SDK 面板使用内联搜索结果，按名称、路径或地址定位；点击结果展开相应内容，不把主列表改成只剩匹配项。搜索结果有明确的数量上限提示，避免大型类型树阻塞界面。

参数配置将 bkp 等共享字段移到独立“公共”页，机械、硬件、软件页只显示各自字段，原始参数路径及设备读写不变。参数表、变量编辑表复用结构体卡片；展开的标题加粗，嵌套卡片逐层小幅内收，名称保持对齐，同组成员不留间隙。右键目标整行高亮，删除操作统一为“删除”；移除右键菜单中的恢复隐藏成员、函数绑定和枚举定义入口，既有配置保持可读取。

变量及结构体复制输出带表头的 CSV，字段为名称、数值、地址；逗号、引号、换行按 CSV 规则转义，保留递归成员和原始位模式格式。

时间轴右键菜单和记录器选项提供“相对时间 / 绝对时间戳”。绝对时间按固定会话时钟基准换算为本地年月日、时分秒和六位微秒，暂停或切换格式不改变采样数据，选择随会话保存。带绝对时间基准的导入文件使用文件基准；缺少基准的文件、触发相对时间及数组索引不会虚构日期，FFT 保持频率轴。

统计浮窗的滚动区域按模式按钮实际占用的高度计算，窄窗口换行后不会超出边界。指标列按当前语言和字体保留完整文字所需的最小宽度，表格两侧保留内边距，文字不贴圆角边缘。通道表头提示仅在别名与原始变量名不同时分两行，名称相同时只显示一次；长名称在视口内换行。

变量管理器中的指针显示完整十六进制地址及指向类型，点击地址打开只读检查窗口；顶层变量、结构体成员和指针数组均可进入。窗口按统一树线与缩进展开标量、结构体、数组和多级指针，空指针、循环引用、读取失败及不完整类型有明确标记。J-Link 使用后台按需读取；断开连接不再追踪，目标切换时不复用旧目标缓存，符号重载使检查窗口失效。LOCAL/SHM 仅查看已注册缓冲区，不直接解引用任意主机地址。预览限制为每数组 64 项、256 行和 12 层，并在达到限制时显示提示。

Windows 顶栏增加“截屏”和“录屏”。截屏读取主窗口当前渲染结果并复制 Windows 图片格式到剪贴板，可直接粘贴；录屏先选择 MP4 保存位置，录制时显示红色停止按钮与时长，停止后后台完成文件并通知结果。记录主窗口客户区，无音频，不包含独立拖出的窗口；视频最高 1920×1080、30 fps，窗口缩放保持比例并留边。编码队列有上限，采集时间戳保留丢帧期间的真实间隔；正常退出会完成录制，成功封装前不覆盖已有目标文件。

指针与画面记录回归：`python tests/run_monitor_ux_test.py --pointers`，包含 32/64 位地址、嵌套数组、循环/空/失效指针、断连与符号重载，以及剪贴板位图、真实 H.264 编解码、改变窗口大小、时间戳、收尾和失败恢复；不连接硬件、不改动系统剪贴板。

截屏与录屏固定在 J-Link 连接按钮所在工具栏的右侧，与连接按钮保持同一行，录制时长变化仍保持右侧对齐，窄窗口自动收起按钮文字。变量管理器的“添加变量”与“添加示波器”共用中性色加号按钮，“监视列表”统一更名“变量列表”。

变量名称列采用紧凑缩进和细树线连接父子节点，深层缩进步长减小；悬停子行时高亮通向上级的连接线与父级名称，其他数据列保持对齐，不再用嵌套大色块表示层级。悬停、选中和右键目标共用整行圆角高亮，右键目标增加更清晰的填色与轮廓；在行内编辑器完成布局后绘制，保持真实行高、冻结列和滚动裁剪。参数表不再叠加树节点原有的矩形悬停底色。菜单和枚举下拉项的高亮也使用圆角。示波器之间保留紧凑间隙，作用域内的控件、右键菜单及下拉框恢复与变量管理器一致的间距。


## 桌面设计统一（2026-10）

采用 [desktop-agent-ui 设计规范](https://github.com/Ludi-Herry/desktop-agent-ui/blob/main/SKILL.md)，继续使用现有 C++ / ImGui / ImPlot。`design_tokens.hpp` 管理 12 / 16 / 20 字号、0.5 px 细线和圆角；缩小字号时正文不低于 12 px。`island_style.hpp` 统一中性表面，`plot_style.hpp` 统一绘图背景、网格及图例，表格层级通过中性色阶和缩进区分。强调色用于交互和状态，曲线保留自身颜色。暂停状态通过标签和按钮表达，不再围绕整个示波器或 dock 画粗色框。

删除常驻的重复操作说明，长说明转移到面板指南；错误、状态、单位和真实设备操作的后果继续保留。界面不再用带空格的中点符号拼接独立信息。工具栏在窄窗口收起文字或换行，文件、设备和数据操作保持分组。悬浮面板使用原生边缘与右下角拖动调整大小；拖动后保持位置和尺寸，Esc 恢复拖动前大小，标题可拖动，长标题自动裁剪。

隐藏 scope 的聚焦使用临时显示状态，不改写已保存的隐藏标记；悬停预览保持稳定，离开或 Esc 恢复隐藏和原视图，点击才展开并固定聚焦。预览不在原位置留下覆盖数据的按钮。表格和隐藏示波器的标题及操作都保持靠右。
