# 跨设备连接（Windows 0.1.38 / Android 0.1.7）

每个 ava_tool 实例都可以共享本机设备，也可以连接另一个实例。两种角色可以同时使用；不会把远端连接再次转发，避免循环。核心协议位于 `src/core/remote_device.*`，桌面和 Android JNI 共用，协议没有绑定 PC 或 Android 角色。

第一版接入 **J-Link 内存读写、设备端普通轮询采样、MCU 复位**。SDK 插件和其他仪器尚未接入。Windows、Android 已构建验证；Linux/macOS 使用同一套桌面入口和 POSIX 传输代码，尚未在对应系统编译及实测。

## 使用

1. 两端使用上述版本或后续兼容版本，连接同一局域网。
2. 接探针的一端先连接本机 J-Link。桌面从 J-Link 连接面板打开“远程设备 → 共享本机”；Android 在“设备 → 本机设备 → 共享本机设备”开启共享。
3. 默认只允许读取。需要修改变量或复位时，在开启共享前勾选“允许远端申请写入控制权”。把本机配对码交给控制端。
4. 控制端打开“连接远端”（Android 为“设备 → 远程设备”），发现局域网设备，或手动输入共享端 IPv4 地址、端口及配对码。默认 TCP 端口为 `45991`。
5. 在现有变量与示波器中使用远端数据。变量名称/类型从控制端的 ELF/AXF 导入，或手动添加地址；协议不会自动传输固件文件。
6. 写入前点击“取得控制权”或“申请 / 释放控制权”。同一设备只允许一个远端写入者；持有控制权时，共享端的本机写入也被阻止。其他已配对实例仍可读取。
7. “切回本机 / 使用本机设备”显式切换数据源；断网不会自动转成本机读写。停止共享会关闭客户端连接并释放控制权。

Android 开启共享后由带通知的前台服务持有 USB 连接，离开界面或锁屏时继续服务远端；本机图表采样仍在离开界面时停止。停止共享、拔出 USB 或进程结束后释放连接。未开启共享时维持原来的后台释放 USB 行为。Android 不要求控制端具有 USB Host 硬件。

## 能力与边界

| 能力 | 第一版行为 |
|---|---|
| 设备发现 | IPv4 UDP `45992`，组播 `239.255.42.100`；网络阻止发现时使用手动 IP |
| 并发 | 最多 8 个连接，多读单写；每个连接有独立采样配置 |
| 普通采样 | 在共享端读取，附共享端单调时钟微秒时间戳，再批量传输；周期至少 20 ms，最高 50 Hz，实际频率受 USB 读取耗时影响 |
| 采样布局 | 最多 32 个块，总数据不超过 4096 字节；每个连接保留最近 256 帧，慢端覆盖旧帧并累计计数 |
| 写入 | 全字节宽度内存写入；不自动重试失败写入；位字段写入暂不支持 |
| 复位 | 必须持有控制权；复位使目标代次失效，需要重新连接 |
| 暂不支持 | 远端 HSS、RTT、SWO、烧录/擦除、暂停/继续 CPU；公网中继、IPv6、自动重连 |

这里的“实时”是遥测和交互控制，不是硬实时闭环。采样限制会在连接页明确显示。桌面采样器复用原有时间戳帧接口，但远端底层仍是普通内存轮询，不会偷偷启动探针 HSS。

固件身份检查仍在桌面共享端执行。控制端加载的符号不等于完成远端固件身份验证；Android 共享端尚无桌面的身份/参数布局校验能力，需要核对目标固件与地址类型。切换数据源、目标断开或复位后，旧代次请求不会作用于新目标。

## 传输

用于受信任局域网。配对码是系统随机源生成的 128 位密钥，以 32 位十六进制字符显示。握手使用随机挑战和 HMAC-SHA256；每条后续消息包含方向、连接随机数及递增序号参与校验，拒绝篡改和重放。配对码不在发现响应里广播。

**数据未加密**，这不是 TLS。配对码持有者具有共享端已开放的读取/申请写入权限。默认不打开共享，也不自动打开防火墙或路由器端口；不要直接映射到公网。手动 IP 连接需要共享端防火墙允许所选 TCP 端口；发现还需要允许 UDP 45992。

协议 `AVA_PEER/1` 采用大端 32 位长度前缀和 UTF-8 JSON。消息最大 192 KiB，内存范围最多 4096 字节且不能跨越 32 位地址边界；连接、读写均有超时。客户端每秒心跳；网络异常或会话结束后释放控制权，写入响应丢失时不会重放。

## 验证（2026-10-27）

- Windows 主程序、Android arm64 APK 编译通过；APK 签名和 16 KiB 对齐验证通过。
- C++ 模拟设备回归：配对失败、只读共享、单写者、本机写入排斥、断线释放、范围边界、目标代次、采样批次。
- 桌面完整集成：SDK 模拟设备导出、连接自身共享端、现有采样器帧格式、切换前后旧请求拒绝，以及原有 RTT 重连和固件身份检查回归通过。
- 独立 Python `hashlib/hmac` 客户端：真实 TCP 分段、重放、消息篡改、超长帧、陈旧代次、多写者争用、设备端时间戳。
- Android 11 / x86_64 模拟器：Android 控制桌面模拟设备、桌面独立客户端控制 Android JNI 模拟设备；真实 UI 配对、变量读数、远端曲线、控制权及切回本机。
- Java 主机 JNI 回调与既有 Android USB/SWD/HSS 模拟回归通过。

以上没有访问物理 J-Link。真实手机 OTG、锁屏长时共享、不同设备之间的 Wi-Fi 吞吐、组播发现及 Linux/macOS 构建仍需对应环境验收。

```sh
python tests/run_remote_device_test.py --jdk <JDK>
python tests/run_monitor_ux_test.py --rtt
python tests/run_android_peer_test.py --sdk <SDK> --jdk <JDK> --serial emulator-5560 --port 5039
python tests/run_android_peer_ui_test.py --adb <adb> --serial emulator-5560 --port 5039
```

Android 测试要求已安装对应 x86_64 测试 APK，仅接受 emulator 序列号，使用模拟内存；测试 instrumentation 不打包进正式 APK。桌面集成测试使用替换的 SDK 函数，不加载探针 DLL。
